# Why this warranty desk has no front end

A warranty team needs the next claim, the supporting evidence, the returned component and the supplier credit in one place. The database holds those records. Claude Code, Codex, OpenCode or Cursor uses the CLI to read and update them in response to the operator.

Read-only HTML pages show the queue, supplier balances and record checks. Draft HTML documents hold assessments, return authorisations, recovery requests and safety review records. Change brand.json to use the business name, logo and colours.

This does not supply a dealer self-service portal, mobile photo capture, offline field synchronisation, drag-and-drop scheduling, customer sign-in or notifications. Evidence references point to documents you keep elsewhere. There are no background jobs and no messages sent. Enterprise DNA can scope those screens and connections for a managed version.

Embedded PGlite is for one local operator process at a time. A controlled PostgreSQL deployment supports shared records but needs identity, permissions, backups, monitoring and operating procedures. The free code does not supply those services. A clean checklist proves only that the implemented checks found no gaps.
